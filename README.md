# earthresourceml.org

Files for the earthresourceml.org and schemas.earthresourceml.org websites.

## This repository is a frozen archive

The EarthResourceML web pages are now at <https://cgi-iugs.org/earthresourceml/> and are edited in the [cgi-iugs.github.io](https://github.com/CGI-IUGS/cgi-iugs.github.io) repository. This site's home page just points there.

Everything else here is kept so that existing URLs keep working. The documentation, XSD schemas and example XML are cited by URL in `schemaLocation` attributes, papers and INSPIRE data.

* Don't move, rename or delete files.
* Keep "Enforce HTTPS" turned off in *Settings → Pages*. Many XML validators use Java's `URLConnection`, which does not follow a redirect from `http://` to `https://`.
* DNS for earthresourceml.org is held by Geoscience Australia.
